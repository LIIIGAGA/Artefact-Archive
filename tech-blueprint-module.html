Modular Narrative System模块化叙事系统

A data-driven modular narrative framework used to organise, manage, and dynamically generate "Spatial Storylet" content within Unreal Engine. 基于数据驱动的模块化叙事框架，用于在 Unreal Engine 中组织、管理和动态生成"空间故事模块"内容。

Demonstration of the modular narrative system in Unreal Engine.模块化叙事系统在 Unreal Engine 中的演示效果。

02
Dice Check骰子检定系统（Dice Check）
Each item carries a specific IDEO attribute value; these are summed to produce the cumulative IDEO value, representing the player's factional tendency. 每件物品都有特定的IDEO属性值，叠加后得到IDEO累计值，代表玩家的阵营倾向。
2d6 random dice value + cumulative IDEO value = final check score. ≥7 is classified as Archivist faction; <7 is classified as Whalemen faction. 2d6随机骰子数值 + IDEO累计值 = 最终检定分数。≥7则判断属于Archivist阵营，＜7则判断属于Whalemen阵营。

After items are collected, the system checks whether the item slots are full; once this condition is met, the Dice Check is triggered. A random 2d6 dice value is added to the cumulative IDEO attribute value of the three items to produce the final dice score, which is compared against a judgement threshold (currently set to 7) to determine factional allegiance. 收集物品之后，判断物品槽已填满，满足条件即可触发骰子检定，将2d6骰子随机值叠加三个物品的IDEO属性值得到最终骰子点数，与判定阈值（目前设定为7）进行比较，判定阵营归属。

3. Dynamic Storylet Generation3. 动态模块生成系统（Dynamic Storylet Generation）

01
Controlled Randomization受控随机生成（Controlled Randomization）
Content is randomly drawn from a pool of modules matching the current faction and phase conditions, improving replayability while preserving narrative coherence.从符合当前阵营和阶段条件的模块池中随机抽取内容，在保证叙事逻辑一致性的同时提升可重复游玩性。
Every future module is pre-placed in the scene but hidden by default. The jump relationships between modules are not fixed, but are managed through Actor Tags. 每个未来模块在场景中提前放置，但默认隐藏。模块之间的跳转关系不固定，而是由Actor Tag进行管理。
This is the key to the system's scalability. When adding a new module, the developer only needs to configure the corresponding tag for the new narrative module to be automatically integrated into the system. 这是整个系统实现可扩展性的关键。新增模块时，开发者只需配置对应标签，即可将新的叙事模块自动接入系统。

All modules pending generation carry an Archivist or Whalemen tag, and are hidden in the environment by default. Based on the relationship between the final dice score and the judgement threshold (currently set to 7), if the score is ≥7, the system retrieves available modules tagged Archivist and randomly generates one; if <7, it retrieves available modules tagged Whalemen and randomly generates one. Once generation is complete, the system clears the submission slots, resets the current round's IDEO value, and proceeds to the next round. 所有待生成模块带有Archivist或Whalemen的tag，初始在环境为隐藏状态。根据最终点数与判定阈值（目前设定为7）的相对大小关系，≥7则检索tag=Archivist的可用模块并随机抽取一个进行生成，＜7则检索tag=Whalemen的可用模块并随机抽取一个进行生成。生成完成后，系统清空提交槽，重置本轮IDEO值，并进入下一轮循环。
