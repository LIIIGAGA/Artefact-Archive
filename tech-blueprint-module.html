Modular Narrative System模块化叙事系统

A data-driven modular narrative framework used to organise, manage, and dynamically generate "Spatial Storylet" content within Unreal Engine. 基于数据驱动的模块化叙事框架，用于在 Unreal Engine 中组织、管理和动态生成"空间故事模块"内容。

Demonstration of the modular narrative system in Unreal Engine.模块化叙事系统在 Unreal Engine 中的演示效果。

2. Narrative Evaluation System2. 叙事评估系统（Narrative Evaluation System）

01
Inventory & Submission背包与物品上缴系统（Inventory & Submission）
Items obtained through interaction with the environment enter the player's inventory; when a module needs to be generated, the player selects any 3 items and places them in the submission slots on the right.玩家与环境交互获得的物品进入背包，在需要生成模块时选择任意3件物品放置到右侧物品槽中。
Content pending.内容待补充。
02
Dice Check骰子检定系统（Dice Check）
Each item carries a specific IDEO attribute value; these are summed to produce the cumulative IDEO value, representing the player's factional tendency. 每件物品都有特定的IDEO属性值，叠加后得到IDEO累计值，代表玩家的阵营倾向。
2d6 random dice value + cumulative IDEO value = final check score. ≥7 is classified as Archivist faction; <7 is classified as Whalemen faction. 2d6随机骰子数值 + IDEO累计值 = 最终检定分数。≥7则判断属于Archivist阵营，＜7则判断属于Whalemen阵营。

3. Data Content Management3. 数据管理系统（Data Content Management）

01
Actor Tag Framework标签框架（Actor Tag Framework）
Every future module is pre-placed in the scene but hidden by default. The jump relationships between modules are not fixed, but are managed through Actor Tags. 每个未来模块在场景中提前放置，但默认隐藏。模块之间的跳转关系不固定，而是由Actor Tag进行管理。
This is the key to the system's scalability. When adding a new module, the developer only needs to configure the corresponding tag for the new narrative module to be automatically integrated into the system. 这是整个系统实现可扩展性的关键。新增模块时，开发者只需配置对应标签，即可将新的叙事模块自动接入系统。

Faction Alignment Branching阵营倾向分支逻辑（Faction Alignment Branching）
This is the core logic that determines narrative direction. Every item carries a hidden ideology value.
